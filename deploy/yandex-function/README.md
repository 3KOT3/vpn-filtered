# Проверка из России в Yandex Cloud Functions

Функция делает то же, что домашний `check.bat`, но живёт в российском дата-центре
Яндекса: гоняет конфиги через sing-box (YouTube → Telegram → дата-центр → скорость)
и публикует результат боту. Компьютер можно выключать.

## Сколько это стоит

**Ноль**, пока не вышли за бесплатный уровень Cloud Functions:

- первые **1 000 000 вызовов** в месяц — бесплатно;
- первые **10 ГБ×час** выполнения в месяц — бесплатно;
- триггеры не тарифицируются.

Наш режим: 512 МБ памяти, ~90 секунд на прогон, раз в 3 часа → около **5 ГБ×час в
месяц**. Это внутри бесплатного лимита. Для аккаунта нужен подключённый платёжный
аккаунт (карта), иначе Yandex Cloud не даст создать версию функции.

## Что нужно сделать (консоль)

### 1. Создать функцию

1. Откройте [консоль Yandex Cloud](https://console.yandex.cloud/) → **Cloud Functions** → «Создать функцию».
2. Имя: `vpn-checker`. Язык: **Python 3.12**.
3. Способ: **ZIP-архив** — загрузите файл `vpn-checker-function.zip` из этой папки.
4. Точка входа: `index.handler`.
5. Память: **512 МБ**, таймаут: **600 секунд**.

### 2. Переменные окружения (на вкладке версии)

| Переменная | Значение |
| --- | --- |
| `WORKER_URL` | `https://moybot.sergeylllilllkin2.workers.dev` |
| `CHECKER_KEY` | `chk-7Qm2xVp9LzR4tNb8sWk3` |
| `PUBLISH_KEY` | `pub-7Qm2xVp9LzR4tNb8sWk3` |
| `MIN_MBPS` | `1.0` (порог скорости) |
| `SOURCES` | `6,22,23` (какие файлы проверять) |

`CHECKER_KEY` — секрет: он умеет только публиковать список и не даёт доступа к боту.
Он живёт в переменных функции, а не в открытом репозитории.

### 3. Расписание

**Триггеры** → «Создать триггер» → **Таймер**:

- cron-выражение: `0 */3 * * * ?` (каждые 3 часа);
- функция: `vpn-checker`;
- версия: `$latest`.

### 4. Проверить

В консоли функции → «Тестировать» → вызвать с телом `{}`. В ответе будет
`{"ok": true, "kept": N, ...}`, а бот покажет новый список.

## Что происходит с результатом

Функция отправляет на воркер:

- `POST /publish?quiet=1` — список и авто-конфиг попадают в KV бота, и он начинает
  отдавать их по ссылкам **всем** клиентам (без лишней рассылки);
- `POST /publish-status` — статус обновляет главный экран бота.

Дальше бот сам раздаёт: `/sub.txt` (v2Box, v2rayNG), `/sub-hiddify.json` (Hiddify).

## Если что-то пошло не так

- **«Размер архива слишком большой»** — архив 31 КБ, это не про нас; проверьте, что
  загрузили ZIP, а не отдельные файлы.
- **Таймаут** — увеличьте таймаут функции до 600 с и память до 1024 МБ (расход
  ГБ×час вырастет, но всё ещё в пределах бесплатного лимита).
- **`kept: 0`** — в источнике сейчас нет живых конфигов; функция не трогает
  прошлый список (код 3 у чекера), бот продолжает отдавать предыдущий.
- **Логи** — консоль функции → «Логи», там весь вывод чекера построчно.
