# Проверка на сервере

Раньше проверку запускал компьютер владельца: пока он включён — список свежий,
выключен — нет. Здесь та же проверка живёт на постоянном хосте в России и
работает сама.

```
┌─ VPS в России ─────────────┐     ┌─ Cloudflare ──────────────┐
│ server.py                  │     │ worker (бот)              │
│  ├─ раз в 6 ч: check.py    │────▶│  POST /progress → полоса  │
│  ├─ кнопка «Обновить»      │     │  POST /publish  → KV      │
│  └─ прогресс в бота        │     │  /sub.txt, /sub-auto.json │
└────────────────────────────┘     └───────────────────────────┘
```

Что это даёт:

- компьютер можно выключать — список обновляется на сервере;
- проверка идёт **из России**, то есть показывает то, что реально работает у вас;
- кнопка «🔄 Обновить» в боте запускает проверку на сервере, а не в GitHub;
- полоса прогресса показывает настоящие проценты (их присылает сам чекер).

## Что нужно

Любой постоянно включённый хост в России: VPS за 150–300 ₽/мес, мини-ПК,
Raspberry Pi, старый ноутбук. Требования: Linux (Ubuntu/Debian) и 512 МБ RAM.

## Установка (5 минут)

### 1. Арендовать VPS

Подойдёт самый дешёвый в российском облаке — Timeweb, reg.ru, aeza, Selectel.
Нужен Ubuntu 22.04 или 24.04, 1 ГБ RAM, любой диск.

### 2. Зайти по SSH

Провайдер покажет IP и пароль root:

```bash
ssh root@<IP>
```

### 3. Скачать этот репозиторий

```bash
apt-get install -y git
git clone https://github.com/3KOT3/vpn-filtered.git
cd vpn-filtered
```

### 4. Запустить установщик

Одна команда — она поставит Python, sing-box, службу и systemd-юнит:

```bash
sudo CHECKER_KEY='придумайте-длинный-пароль' \
     WORKER_URL='https://moybot.sergeylllilllkin2.workers.dev' \
     bash deploy/checker-service/install.sh
```

Параметры (все необязательные, кроме первых двух):

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `CHECKER_KEY` | — | пароль службы, тот же впишем в бота |
| `WORKER_URL` | — | адрес воркера бота |
| `INTERVAL_HOURS` | `6` | как часто проверять |
| `MIN_MBPS` | `2.0` | порог скорости |
| `SOURCES` | из `config.json` | какие файлы проверять, например `6` |
| `PORT` | `8099` | порт службы |

### 5. Прописать адрес в боте

Пришлите адрес `http://<IP>:8099` и пароль — бот запомнит их в переменных
`CHECKER_URL` и `CHECKER_KEY`. После этого кнопка «🔄 Обновить» работает через
сервер.

## Проверка, что всё живо

```bash
curl http://127.0.0.1:8099/health
journalctl -u vpn-checker -f          # логи
curl -X POST 'http://127.0.0.1:8099/check?key=ПАРОЛЬ'   # запустить сейчас
```

## Если хост без белого IP

Служба сама стучится наружу, входящий порт нужен только боту. Если IP
динамический или закрыт, есть два пути:

- пробросить порт на роутере (если это домашний мини-ПК);
- поставить Cloudflare Tunnel: `cloudflared tunnel --url http://127.0.0.1:8099`
  и использовать выданный адрес как `CHECKER_URL`.

## Windows-мини-ПК

Тот же `server.py` запускается и на Windows:

```bat
set CHECKER_KEY=пароль
set WORKER_URL=https://moybot.sergeylllilllkin2.workers.dev
set SING_BOX=C:\путь\к\sing-box.exe
python server.py
```

Чтобы работало без входа в систему — «Планировщик заданий» → «При запуске
компьютера» → `python server.py`.

## Тесты

```bash
python deploy/checker-service/test_service.py
```

Проверяет службу целиком: запуск по ключу, отказ чужому ключу, отсутствие
дублей, приход прогресса и публикацию списка (воркер подменяется заглушкой).
